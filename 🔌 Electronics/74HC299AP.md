# 74HC299AP

Toshiba **TC74HC299AP** — DIP-20 korpusli, 8-bit universal shift registr. To‘rtta rejimi bor: saqlash, o‘ngga siljitish, chapga siljitish va parallel yuklash. Ta’minot diapazoni **2–6 V**. [Toshiba datasheet, PDF](https://toshiba-semicon-storage.com/info/TC74HC299AF_datasheet_en_20140301.pdf?did=15754&prodName=TC74HC299AF).

## IC: DIP-20

Yuqoridan ko‘rinish; o‘yiq tepada. `/` faol-past signalni bildiradi. `QA′` va `QH′` — alohida serial chiqishlar, inversiya emas.

```ic{DIP-20} Toshiba TC74HC299AP
1: S0
2: /G1
3: /G2
4: G / QG
5: E / QE
6: C / QC
7: A / QA
8: QA'
9: /CLR
10: GND
11: SR
12: CLK
13: B / QB
14: D / QD
15: F / QF
16: H / QH
17: QH'
18: SL
19: S1
20: VCC
```

Pinlar va rejimlar uchun qo‘shimcha ishlab chiqaruvchi manbasi: [ST M74HC299, 2-bet](https://www.st.com/resource/en/datasheet/m74hc299.pdf#page=2). Boshqa ishlab chiqaruvchi variantining elektrik limitlarini Toshiba chipiga ko‘chirmang.

## Rejimlar

`/CLR = HIGH` bo‘lganda:

| S1 | S0 | Rejim | CLK ko‘tariluvchi frontidagi amal |
| --- | --- | --- | --- |
| 0 | 0 | HOLD | Qiymat saqlanadi |
| 0 | 1 | SHIFT RIGHT | SR → QA → QB → … → QH |
| 1 | 0 | SHIFT LEFT | SL → QH → QG → … → QA |
| 1 | 1 | PARALLEL LOAD | A–H kirishlari registrga yoziladi |

`/CLR = LOW` registrni clocksiz tozalaydi. Parallel LOAD rejimida sakkizta I/O chiqishi avtomatik yuqori impedansga o‘tadi. Boshqa rejimlarda chiqishlarni yoqish uchun `/G1 = /G2 = LOW`; ulardan bittasi HIGH bo‘lsa ham I/O chiqishlar uziladi. Ichki siljitish davom etishi mumkin. [ST funksional jadvali](https://www.st.com/resource/en/datasheet/m74hc299.pdf#page=2).

## Parallel ma’lumotni serial o‘qish

1. `/CLR = HIGH`, `S1 = S0 = HIGH` qiling.
2. A–H ga bayt qo‘yib, CLK impulsini bering.
3. `S1 = LOW`, `S0 = HIGH` tanlang.
4. QH′ orqali avval H bitini o‘qing; har clockdan keyin keyingi bit keladi.

Bu tartib SHIFT RIGHT jadvalidan kelib chiqadi. Tashqi qurilma I/O pinlarini boshqarayotgan paytda chipning parallel chiqishlarini o‘chiq tuting.

> [!WARNING]
> I/O pinlarini chip chiqish rejimida turganida tashqaridan boshqarmang. Toshiba suzuvchi bus pinlariga pull-up yoki pull-down qo‘llashni ham talab qiladi.

## 74HC595 bilan farqi

299 ikki tomonga siljitadi va parallel yuklaydi; 595’da shift registrdan alohida chiqish latch’i bor. 299’da 595’dagi kabi alohida latch clock yo‘q. Shu sabab siljitish davomida parallel chiqishlarda o‘zgarish ko‘rinishi mumkin.
