# Zilog Z80

[Микро 80. Игры, Бейсик и ремонт видеоплаты. #11](https://www.youtube.com/watch?v=8NhO5Pngzx0)

Z80 — 8-bit ma’lumot shinasi va 16-bit manzil shinasiga ega mikroprotsessor. To‘g‘ridan-to‘g‘ri 64 KiB xotirani adreslaydi. Dastur va ma’lumot uchun tashqi ROM/RAM ishlatiladi. [Zilog CPU qo‘llanmasi, PDF](https://www.z80ne.com/datasheets/z80.pdf).

## Asosiy xususiyatlar

| Xususiyat | Qiymat |
| --- | --- |
| Ma’lumot shinasi | D0–D7, 8 bit |
| Manzil shinasi | A0–A15, 16 bit |
| Xotira manzillari | 0000h–FFFFh, 64 KiB |
| Ta’minot | +5 V |
| Ushbu pinout korpusi | DIP-40 |
| Interrupt rejimlari | IM 0, IM 1, IM 2 va alohida NMI |
| Qo‘shimcha imkoniyat | DRAM refresh hisoblagichi |

NMOS va CMOS variantlari bor. Takt chastotasi aniq modelga bog‘liq: masalan, Z84C0020 uchun DC–20 MHz ko‘rsatilgan. [Zilog Z8400/Z84C00 Product Brief, PDF](https://www.mouser.com/datasheet/2/450/z8400-36282.pdf).

## Boshqaruv signallari

| Signal | Vazifasi |
| --- | --- |
| `/MREQ` | Xotiraga murojaat |
| `/IORQ` | I/O murojaati yoki `/M1` bilan interrupt acknowledge |
| `/RD`, `/WR` | O‘qish va yozish |
| `/M1` | Opcode fetch; interrupt acknowledge siklida ham ishlatiladi |
| `/RFSH` | `/MREQ` bilan DRAM yangilash sikli |
| `/WAIT` | Sekin xotira yoki periferiyani kutish |
| `/BUSRQ`, `/BUSACK` | Shinani tashqi qurilmaga berish va tasdiqlash |
| `/HALT` | HALT holati chiqishi |
| `/INT`, `/NMI` | Maskalanadigan va maskalanmaydigan uzilish |
| `/RESET` | CPU boshlang‘ich holatini o‘rnatish |

Signal yo‘nalishlari va timing: [Zilog qo‘llanmasi, Pin Functions](https://www.z80ne.com/datasheets/z80.pdf#page=27).

## Registrlar

- `A`, `F`: akkumulyator va holat bayroqlari.
- `BC`, `DE`, `HL`: umumiy registr juftliklari; `AF′`, `BC′`, `DE′`, `HL′` — muqobil to‘plam.
- `IX`, `IY`: 16-bit indeks registrlari.
- `PC`, `SP`: dastur va stek ko‘rsatkichlari.
- `I`, `R`: interrupt vektori va refresh registrlari.

Muqobil registrlar to‘plami kontekstni tez almashtirishga yordam beradi. [Zilog Product Brief](https://www.mouser.com/datasheet/2/450/z8400-36282.pdf).

## Ishga tushirish

Minimal tizimga CPU, clock, reset, dastur ROM’i va manzil dekoderi kerak; ishchi xotira uchun RAM qo‘shiladi. `/RESET` kamida uchta to‘liq clock sikli davomida past bo‘lishi kerak. Resetdan keyin `PC = 0000h`, interruptlar o‘chirilgan va rejim `IM 0` bo‘ladi. [Zilog qo‘llanmasi: RESET](https://www.z80ne.com/datasheets/z80.pdf#page=29), [Minimum System](https://www.z80ne.com/datasheets/z80.pdf#page=47).
